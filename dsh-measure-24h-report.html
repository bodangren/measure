What was actually improved

Nine themes, each backed by an archived track with a dated review and a green gate run.

Guard performance without blindness

measure-guardunit-tested

The host used to invalidate every cached snapshot after every tool result — correct but so heavy it re-read measure/ on each call. Snapshots now refresh only for tools that can mutate the repository, with a disjoint tool-classification test pinning both sides.

Why it matters: a fast guard gets left on; a guard that is turned off protects nothing.

Tracks: snapshot_invalidate · fix2 · fix3

Commit guard with real teeth

commit guard38 unit cases

The strict commit guard now fails closed when a command substitution hides a git add, scans nested shells and git stage, steps over shell option arguments (-euo, --rcfile, --init-file) and wrapper/env prefixes, counts only short -c clusters, honours --, and reads added paths with a real shell-word tokenizer (quotes, escapes, comments) instead of a whitespace regex.

Why it matters: an under-approximating guard let a data file ride into a test-only mid-red commit; each fix closes one parser hole with a negative test that would catch its return.

Tracks: substitution · nested · fix2 · fix3 · fix4 · fix5 · add_quoting · token_scan

Shell-write grammar: fewer false denials, same real blocks

shell scanunit-tested

The redirect scan now masks heredoc bodies (through the delimiter, tab-aware for <<-), > inside quoted spans, and # comments before looking for >/>> — and only recognises heredoc markers outside quotes. Real writes still deny; a document quoting > measure/tracks.md no longer does.

Why it matters: false positives train operators to weaken the guard; false negatives lose work. Both directions are now pinned by tests.

Tracks: shell_grammar · allow_parse

Registry and closeout can no longer drift

measure CLIchecker suite

The registry checker now proves every archive directory appears exactly once, the active/cancelled/archived sections stay separate, and each registry description equals its metadata description. Closeout verifies the same before it reports done — it caught two of its own recent tracks in the act.

Why it matters: the registry is the project index; a wrong line there misleads every future session. The check now fails the build, not the reader.

Tracks: registry · fix2 · fix3 · fix4 · closeout_registry · scope_intermediate

Spec-review gate that proves itself

11 suitesadversarial

The gate runner now refuses to run itself, skips symlinked suites, rejects glob-metacharacter names instead of silently running something else, and fails when a unittest file runs zero tests (the Python ≤3.11 trap). The dispositions parser rejects control characters, zero-width and bidi marks, and matches markers exactly; the A11 doc-drift recipe skips executable command spans and pins its space rule.

Why it matters: the gate is the last line of defence for every track, so it must be adversarially tested against itself, not just against tracks.

Tracks: srg_runner · parser · parser fix2 · parser fix3 · a11 · a11 fix2 · a11 fix3 · mktemp guard

Skill descriptions held to contract

CLI suiteskill doctor

A repository check now enforces the 1024-character SKILL.md description limit, keeps the claude-skills/measure bundle free of folder links, honours the real folder-link rule (anchors and schemes skipped), and pins the folded > description form with a fixture.

Why it matters: descriptions are the agent-facing contract; an over-long or folder-linked description silently breaks skill loading in hosts.

Tracks: skill_doctor_check · fix2 · fix3 · fix4

Audit role: proposals, not writes

role contractalias + doc pins

The audit example uses schema_version 1; role-gate --role orchestrator-audit (and the measure-orchestrator-audit alias) validates the result; Inputs, Detectors and Outputs describe catalog and guard-test proposals with a defined candidate format (PROPOSAL: naming the path and assertion) that matches the role's edit permissions. Doc tests pin the schema version, the format, and the absence of the old append/write instructions.

Why it matters: the audit role's contract is what makes its findings actionable; a write instruction the role cannot perform produced dead feedback for weeks.

Tracks: audit_contract · fix2 · fix3 (in flight)

Operator surface & agent-team rehearsal

DSHguides

A one-command, verifiable DSH Measure development environment (guide, CLI, workflow commands, live migration); a compact one-line status band with a strict compactBand contract; operator controls for effective mode and on-demand verification; a disposable-fixture agent-team rehearsal protocol with its review corrections; an isolated-session strict-deny proof; and config-nonce profile reload that no longer relies on a comment marker.

Why it matters: the framework is only real if it survives a cold environment, a broken reload, and an agent team that follows the protocol literally.

Tracks: dev · guard plugin · evolve · ops · band · band fix · rehearsal · isolated session · reload
