## Round 1

Date: 2026-11-07
Reviewer: subagent (fresh context, default model)

### What this track proposes
This track closes the DSH adapter's deferred layers on a POSIX host: strict-mode TDD and commit guards wired onto the `tools/pre-execute` and `tools/post-execute` seams, a writer count that claims only root agents, a DSH goal bound to the active Measure track by a new `/measure-goal` command plus a goal line in the band, progress line, panel, and state route, and an in-band setup answer served by one exact `POST /measure-guard/setup` route. It also appends a Phase S7 that widens the shared registry parser to the numbered execution-order and same-line `*Link:*` forms the Mediarr registry uses, in the canonical mod and both adapter copies. Every story is meant to land with named `node:test` files, the shared-core parity gate, a live check against the running web profile, and closeout documents.

### How the current system works, per this spec
The `plugins/dsh-measure-guard/` bundle runs as one Host plugin with in-memory per-agent state, a snapshot cache, a required `inject` list that already includes `agents` and `subprocess`, three commands, eight workflow commands, the `measure_status` tool, and one exact `GET /measure-guard/state` route that the hand-written Client band and panel poll. Its modes are `advise`, `guard`, and `strict`, but `strict` adds nothing today: the edit, closeout, and end-of-turn guards behave the same in every mode, and the writer record counts every attached agent, so a root plus its subagent reads as two sessions. The setup offer has no button: the first denied edit records `off` in agent state, so the core's `setup` answer and its "setup requested" band variant are unreachable. The shared core already carries every decision function the track needs (`tddDecision`, `redFor`, `taskKey`, `parseCommitCommand`, `commitDecision`, `commitReminder`, `setupBandText`), and the parser reads only the classic `- [~] **Track: …**` plus next-line `*Link:*` shape, so a numbered Mediarr registry yields no tracks and a parse error.
